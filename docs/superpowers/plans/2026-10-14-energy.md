# Énergie ⚡ — Plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rythmer l'apprentissage avec une jauge d'énergie (5 ⚡ max) : commencer une leçon ou un dialogue coûte 1 ⚡, défier le boss 3 ⚡, une séance de révision rend 1 ⚡, et l'énergie remonte de 1 toutes les 3 h.

**Architecture:** Un module pur `services/energy.ts` rejoue le journal d'événements (dépenses `session_started`, gains `review_session_completed`, recharge temporelle). Les dépenses sont enregistrées comme événements **locaux** (jamais envoyés au serveur : la base n'accepte que 5 types d'événements et l'énergie n'est pas vérifiée côté serveur, spec §1). `ActivityService` expose `getEnergy` / `startSession` ; l'état global (`useAppState`) porte `energy`, affiché par un indicateur dans l'en-tête ; les écrans leçon, dialogue et boss vérifient l'énergie avant de démarrer.

**Tech Stack:** Vite 5, React 18, TS strict (noUncheckedIndexedAccess, exactOptionalPropertyTypes), Tailwind 3.4 (tokens), motion 11, Zustand 5, Vitest + Testing Library, Playwright.

**Spec:** [`docs/superpowers/specs/2026-10-14-progression-boss-energy-design.md`](../specs/2026-10-14-progression-boss-energy-design.md) §1 et §4 (étape 3 du §8). Écart assumé : `session_started` est un événement **local uniquement** (voir Global Constraints) ; la spec est mise à jour à la tâche 5.

## Global Constraints

- Aucune nouvelle dépendance ; architecture hexagonale (features/ui n'importent jamais `src/adapters/**`, pas d'import feature→feature, `src/services/**` pur : pas de React, DOM, `Date.now`, `Math.random`).
- Textes d'interface uniquement dans `src/i18n/fr.ts` (français, tutoiement) ; code/commentaires/commits en anglais.
- Couleurs uniquement via les tokens Tailwind ; animations seulement `transform`/`opacity`, durées de `src/ui/motion.ts`.
- Constantes (spec §4) : **max 5**, plein au départ ; **leçon −1**, **dialogue −1**, **boss −3** ; **révision terminée +1** ; **+1 toutes les 3 h** (10 800 000 ms) ; plafond 5 ; jamais sous 0.
- Jamais bloqué : révision, classement, profil, réglages. Refaire une leçon (y compris « Réessayer » après un échec) coûte aussi 1 ⚡.
- `session_started` : `{ type: "session_started", refId, xp: 0, payload: { kind: "lesson" | "dialogue" | "boss" } }`, ajouté au journal **local** (`ProgressRepository.appendEvent`) mais **jamais** mis dans l'outbox ; `SupabaseEventSink` filtre aussi ce type par sécurité.
- Le serveur ne change pas (aucune migration).
- Commits signés uniquement par l'utilisateur (identité git configurée) : jamais de `Co-Authored-By`, jamais de mention de Claude/IA.
- `npm run verify` vert avant chaque commit ; `npm run test:e2e` vert à la fin.

```ts
import type { AppEvent, AppEventType, EnergyState, SessionKind } from "@/domain/types";

export const ENERGY = { max: 5, refillMs: 10_800_000, cost: { lesson: 1, dialogue: 1, boss: 3 }, reviewGain: 1 } as const;

/** Recorded in the local journal only: the server neither accepts nor needs them (energy is not checked server-side). */
export const LOCAL_ONLY_EVENT_TYPES: readonly AppEventType[] = ["session_started"];

const isKind = (v: unknown): v is SessionKind => v === "lesson" || v === "dialogue" || v === "boss";

/**
 * Replays the journal: session starts spend, finished reviews give, and +1 comes back every 3 h counted from the
 * moment energy dropped below the maximum (the timer stops while full). Pure: `nowIso` is injected.
 */
export function energyAt(events: readonly AppEvent[], nowIso: string): EnergyState {
  let current: number = ENERGY.max;
  let anchor = 0; // start of the running refill period (ms), meaningful only below the maximum
  const regen = (t: number) => {
    if (current >= ENERGY.max) return;
    const gained = Math.floor((t - anchor) / ENERGY.refillMs);
    if (gained <= 0) return;
    current = Math.min(ENERGY.max, current + gained);
    anchor += gained * ENERGY.refillMs;
  };
  const sorted = [...events].sort((a, b) => a.createdAt.localeCompare(b.createdAt));
  for (const e of sorted) {
    const t = Date.parse(e.createdAt);
    regen(t);
    const wasFull = current >= ENERGY.max;
    if (e.type === "session_started" && isKind(e.payload["kind"])) {
      current = Math.max(0, current - ENERGY.cost[e.payload["kind"]]);
      if (wasFull && current < ENERGY.max) anchor = t;
    } else if (e.type === "review_session_completed") {
      current = Math.min(ENERGY.max, current + ENERGY.reviewGain);
    }
  }
  const now = Date.parse(nowIso);
  regen(now);
  return { current, max: ENERGY.max, nextAt: current >= ENERGY.max ? null : new Date(anchor + ENERGY.refillMs).toISOString() };
}

export function waitParts(nowIso: string, nextAt: string): { hours: number; minutes: number } {
  const minutes = Math.max(0, Math.ceil((Date.parse(nextAt) - Date.parse(nowIso)) / 60_000));
  return { hours: Math.floor(minutes / 60), minutes: minutes % 60 };
}
```
