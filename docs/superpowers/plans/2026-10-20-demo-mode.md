# Demo Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A separate demo deployment where Marc can test everything alone on his phone — real lessons, real microphone, fake backend with auto-playing opponents — plus a demo panel to grant xu / Kim bài, unlock duels and receive a challenge.

**Architecture:** The app already runs on fakes when `VITE_USE_FAKES=true` (real content, real local Dexie progress, fake auth/leaderboard/duels). A new explicit flag `VITE_DEMO=true` allows that on a non-local host (today refused by `shouldRefuseFakes`), shows a permanent « Mode démo » badge and a demo panel in « Moi ». Grants are a local-only event `demo_grant { coins, kimBai }` counted by the wallet; it can never reach the server (local-only list, and the server's type check would refuse it). The demo is published as a Netlify **deploy preview** of a never-merged PR from a `demo` branch (`[context.deploy-preview.environment]` in `netlify.toml`), so no Netlify setting is needed; its origin is separate, so its storage never mixes with the real app.

**Tech Stack:** Vite 5, React 18, TS strict, Zod 3, Vitest, Playwright, Netlify.

**Spec:** this plan (feature agreed with Marc on 2026-10-19: « version démo … données fictives … bouton +500 xu … n'existe que là »).

## Global Constraints

- No new dependency. TS strict; no `any`, `enum`, `@ts-ignore`, no `x!` outside tests; `@/` imports; ESLint boundaries (features/ui never import adapters/content; app-hooks never import features; services pure).
- UI strings in `src/i18n/fr.ts` (French, tutoiement). Tokens only.
- **Production safety:** without `VITE_DEMO=true` nothing changes: no badge, no panel, fakes still refused on non-local hosts in production builds; `demo_grant` is in `LOCAL_ONLY_EVENT_TYPES` and is never created outside demo mode.
- **Demo env (deploy previews only):** `VITE_USE_FAKES=true`, `VITE_DEMO=true`, `VITE_FAKE_SPEECH=false` (real microphone and voices). The production context keeps today's variables.
- **Demo panel actions (exact):** « +500 xu » (`demo_grant { coins: 500, kimBai: 0 }`), « +20 Kim bài » (`demo_grant { coins: 0, kimBai: 20 }`), « Débloquer les duels » (completes `l01`, `l02`, `l03` and `d01` through the normal activity API if not done), « Recevoir un défi » (fake member challenges me via the fake gateway's incoming-duel helper). Each shows a toast and refreshes progress.
- **Commits: Marc only; never `Co-Authored-By`, never a Claude/AI mention.** `npm run lint && npm run verify` green before DONE.
