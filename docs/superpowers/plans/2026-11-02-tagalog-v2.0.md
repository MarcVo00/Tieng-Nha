# Tagalog 2.0 — plusieurs langues, implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make Tiếng Nhà multi-language and ship a speaking-first Tagalog travel course (8 lessons, 8 dialogues, pre-generated voice, stress respelling), chosen from a language picker and switchable from the home screen.

**Architecture:**
- A language is data:
  - a registry (`src/domain/languages.ts`) gives each language its speech code, id prefix and voices;
  - content lives in `src/content/<language>/`;
  - new content ids carry the language prefix (`tl_l01`); Vietnamese ids stay unprefixed;
  - the event log, the reviews and the server keep working unchanged.
- The active language is a local setting:
  - the services provider hands every screen the content source of that language;
  - the routed screens remount when it changes.
- Shared across languages: hero, xu, gacha, energy, streak, daily bonus, XP and the shared files (badges, shop, changelog).

**Tech Stack:** Vite 5, React 18, TS strict, Tailwind tokens, motion 11, Zustand, Dexie, Zod, Vitest, Playwright; voices pre-generated with `edge-tts` (Python, free), see Task 9.

**Spec:** `docs/superpowers/specs/2026-11-02-tagalog-and-languages-design.md`. This plan covers version **2.0.0** (spec §4.6). The boss, the Tagalog badges and the certificate (2.1) and the duels (2.2) get their own plans.

## Global Constraints

- Stack frozen: no new npm dependency without an ADR (this plan adds none; `edge-tts` is a Python tool outside the npm build, like VieNeu-TTS in ADR 0011).
- Architecture:
  - hexagonal (ADR 0001), ESLint boundaries;
  - components never import `src/adapters/`;
  - app hooks in `src/app/use*.ts` never import features.
- UI text in French in `src/i18n/fr.ts`:
  - U+202F inside « » and before `? ! : ;` ;
  - NBSP before units (`10 xu`) ;
  - always written as ` ` / ` ` escapes in TS sources (no-irregular-whitespace lint).
- `lang` attribute on target-language text: `vi` for Vietnamese, `tl` for Tagalog (from the registry, never hard-coded in shared components).
- Existing ids never change:
  - `l01`–`l10`, `d01`–`d10`, `v_*`, `exam_q*`, `boss_thuy_tinh` stay as they are;
  - new Tagalog ids: `tl_l01`–`tl_l08`, `tl_d01`–`tl_d08`, `tl_v_<word>`, exercise ids `tl_l01_e01`…
- Tagalog uses only `listen_choose`, `translate_choose`, `word_order`, `speak` (no `tone_pick`).
- Stress respelling (`pron`):
  - syllables joined by U+00B7 `·`, the stressed syllable in capitals: `sa·LA·mat`, `ma·GAN·dang u·MA·ga` ;
  - every respelling comes from a free source that marks stress (first choice: English Wiktionary IPA) ;
  - a word with no reliable source is not taught.
- No server migration in 2.0. A 1.11 client still open must keep working.
- Commits signed by Marc only: never `Co-Authored-By: Claude`, never « Generated with Claude Code ».
- Shell safety: always quote paths (the repo path contains a space, `IT Projects`); never `rm -rf` outside the repo; `ls` before deleting.
- `npm run verify` green before a task is done; e2e green before release.
